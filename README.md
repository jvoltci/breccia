# breccia

A cross-framework block-scaled tensor primitive for low-precision compute
(FP8 / FP4 / MXFP8 / NVFP4 / INT4).

> Sister library to [`scree`](https://github.com/jvoltci/scree). scree handles
> variable-length data; breccia handles low-precision data bound by its scale.
